# Convert Brand Hub

Planning project for a staff-friendly Convert brand guide, asset library and stack image creator. No application has been built.

## Project boundaries

This is a separate application and repository from Convert Product UI. Its interface will consume a specific released version of `@convert/product-ui`. Storybook remains the developer reference for that library.

The general brand identity and the product interface have different typography rules. The brand serif may appear in brand examples and exported artwork, but never in interface controls or application navigation.
